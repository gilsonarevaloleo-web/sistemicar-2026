### 1. INYECCIÓN DEL PROMPT DE RAZONAMIENTO A GEMINI
Cuando el usuario responde una Fase (por ejemplo, la Fase 1) y solicita avanzar a la siguiente (Fase 2):
1. Envía a la API de Gemini:
   - El Código Activo (ej. Código 1.3 - Tiempo).

   - El marco del Código de Sistemicar actual.

2. Pídele a Gemini que actúe bajo la persona del "Gobernador de Sistemicar":
